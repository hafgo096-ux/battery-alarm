## 🐞 گزارش تحلیل و رفع باگ‌ها (نسخه‌های قبلی)

### الف) باگ «فراموش شدن تنظیمات» ✅ رفع شد
- بارگذاری با `WebViewAssetLoader` روی دامنه امن `https://appassets.androidplatform.net/assets/`
- `MonitorPrefs` + `settingsJson()` / `setSetting()`: ذخیره دائمی در `SharedPreferences`
- هر ۱۵ کلید تنظیمات تایپ‌دار ذخیره می‌شوند

### ب) باگ‌های مصرف باتری ✅ رفع شد
- حذف کامل `WakeLock` و `WAKE_LOCK`
- پایش **رویدادمحور** (فقط `ACTION_BATTERY_CHANGED`) بدون تایمر مکرر
- کش‌گذاری (CPU ۱.۵s، رم ۱.۲s، حافظه ۴s)
- «حالت کم‌مصرف» با `JobScheduler` هر ۱۵ دقیقه + کلید خاموش‌کردن کامل

### ج) قابلیت‌ها
- کنترل بلندی صدای هشدار (اسلایدر ۰-۱۰۰٪)
- اسکنر واقعی کش برنامه‌ها (`StorageStatsManager`)
- فایل‌های حجیم رسانه‌ای (`MediaStore`)
- پاکسازی امن کش خود برنامه
- مدیریت از تنظیمات اندروید (برنامه هرگز فایل دیگران را حذف نمی‌کند)
