# 🔋 هشدار هوشمند شارژ باتری و پایش سخت‌افزار (نسخه اولیه ۱.۰.۰)
### Battery Alarm & Hardware System Monitor - Version 1.0.0

برنامه اندرویدی پیشرفته و مدرن برای هشدار هوشمند شارژ باتری گوشی به همراه مانیتورینگ دقیق و لحظه‌ای وضعیت **پردازنده (CPU)**، **حافظه موقت (RAM)** و **حافظه ذخیره‌سازی موجود (Storage / ROM)**.

---

## ✨ ویژگی‌های نسخه ۱.۰.۰ (انتشار اولیه)

- ⚡ **هشدار شارژ باتری هدف (پیش‌فرض ۸۵٪)**: محافظت از سلامت باتری و جلوگیری از Overcharge با امکان تنظیم درصد از ۴۰٪ تا ۱۰۰٪
- 🧠 **مانیتورینگ زنده سی‌پی‌یو (CPU)**: نمایش مدل پردازنده، تعداد هسته‌ها، کلاک فرکانس و بار مصرفی پردازنده
- 📊 **مانیتورینگ رم (RAM)**: نمایش دقیق حجم کل رم، رم مصرف‌شده و **حافظه رم آزاد و موجود**
- 💾 **مانیتورینگ حافظه داخلی (Storage)**: نمایش کل ظرفیت، فضای پر شده و **فضای خالی و در دسترس** با تفکیک هوشمند
- 🔔 **سیستم هشدار چندگانه**:
  - ۸ زنگ دیجیتال سینتیزه‌شده اختصاصی
  - صداهای گوینده و زنگ‌های شخصی‌سازی شده
  - امکان تست و پیش‌نمایش زنده صدا
- 📳 **ویبره الگو دار و اعلان‌های سیستمی**: زنگ فقط با لمس دکمه «توقف زنگ» قطع می‌شود
- 🛡️ **سرویس پایدار پس‌زمینه (Foreground Service)**: زنده ماندن پایش حتی هنگام بستن برنامه از Recent Apps یا در حالت Doze Mode
- 🔄 **راه‌اندازی خودکار بعد از روشن شدن گوشی (Boot Receiver)**
- 🎨 **طراحی رابط کاربری از صفر**: طراحی نئونی فوق‌العاده شیک، واکنش‌گرا و AMOLED به زبان فارسی (RTL)
