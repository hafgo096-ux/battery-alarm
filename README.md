# هشدار شارژ باتری ۸۵٪ | Battery Charge Alarm

برنامهٔ اندرویدی هشدار شارژ باتری که هنگام رسیدن شارژ گوشی به ۸۵٪ (قابل تنظیم) زنگ هشدار می‌دهد.

## ویژگی‌ها

- 🎯 درصد هدف قابل تنظیم (پیش‌فرض ۸۵٪)
- 🔔 ۸ زنگ سینتیزی + ۷ صدای شخصی
- 📳 لرزش و اعلان سیستمی
- 🔋 پایش پس‌زمینه حتی زمانی که برنامه بسته است (Foreground Service)
- 🚀 اجرای خودکار بعد از روشن شدن گوشی (Boot Receiver)
- 🌙 رابط گرافیکی فارسی و راست‌چین

## نیازمندی‌ها

- اندروید ۸.۰ (API 26) یا بالاتر
